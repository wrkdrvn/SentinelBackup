Agent Installer

SentinelBackup Agent

Ein interaktiver Installer fuer alle Zielservertypen (ISPConfig, MailCow, Docker/Portainer).

Anleitung
  1. Laden Sie die Datei setup_agent.sh herunter.
  2. Uebertragen Sie sie auf den Zielserver (z. B. scp setup_agent.sh root@ziel:/root/).
  3. Fuehren Sie sie als Root aus: sudo bash setup_agent.sh
  4. Der Installer fragt den Servertyp ab, richtet den Agenten unter /opt/sentinel_agent/ ein, erzeugt das Backup-Skript und traegt den Cronjob automatisch ein.
  5. Fuegen Sie den Server anschliessend im SentinelBackup WebUI hinzu. Die Standardpfade sind bereits vorausgefuellt:
    Backup-Pfad: /opt/sentinel_agent/data/
    Flag-Pfad:   /opt/sentinel_agent/.backup_done
